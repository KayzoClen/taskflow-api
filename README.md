# taskflow-api - API de gestion de taches.

## ***Installer la dépendance node***

*installer npm*
```bash
npm install
```
*puis la bonne version de express*
```bash
npm install express@4.19.2
```

## Quelles sont les manques / incomplets:

Bug sur router.post dans le fichier `tasks.js`

`config.js` contient le port utilisé et l'admin APIKEY
