# TaskFlow API

TaskFlow API est une API REST légère et rapide conçue pour simplifier la gestion quotidienne de listes de tâches.

---

## Stack technique employée

- **Runtime** : Node.js (v18+)
- **Framework Web** : Express.js (v4.19.2)
- **Langage** : JavaScript (CommonJS)
- **Gestionnaire de paquets** : npm

---

## Installation


```bash
git clone https://github.com/KayzoClen/taskflow-api.git
cd taskflow-api
npm install
npm start
```

Le serveur sera alors accessible à l'adresse suivante : `http://localhost:3000`.
