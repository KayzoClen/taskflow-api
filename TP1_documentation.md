# Session 1: TP1 documentation (groupe Thibaud Herry, Romain Carrere)

### *Here are the different files and config files you need to know about before going into the project!*

| Doc | Type | Qui produit? | Qui relit? | Où stocker? |
| --- | --- | --- | --- | --- |
| Ex: README | Tutoriel | Dev | Un pair | Dépôt |
| config.js | Config file | Dev | Un pair | Dépôt |
| package.json | Config file | Logiciel | Dev | Working directory |
| server.js | code file | Dev | Un pair | Dépôt |
| .gitignore | config file (non présent / à rajouter) | Logiciel ou Dev | Dev / un pair | Dépôt |
| commentaires | documentation | Dev | Dev / un pair | Dépôt |

## Nos critères pour le bon lancement du projet : 

- Titre explicite sur le projet pour le comprendre en 2 secondes
- Initialisation du projet et installation des dépendances
- Lisibilité du README en général
- Préciser ce qui est incomplet / à compléter dans le projet
- Un contact en cas de question / toute demande de la part d'un Dev ou d'un utilisateur
